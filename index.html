📖 User Guide

⚠️ Important: All data on this site is stored only in your browser on this device. It is never uploaded to any server. Read this guide to understand the risks before using the app.
🗺️ Features Overview
🏆
Dashboard
View total profit, loss, and net P&L across all stakeholders. Filter by stakeholder, stock, trade type, and date range. Includes a live leaderboard, market sentiment indicator, and stock performance breakdown.
➕
Log Trade
Record a new trade by selecting a stakeholder and stock, then entering buy price, sell price, and quantity. The app automatically calculates profit/loss amount, trade type, and return percentage — no manual entry needed.
📋
Trade History
Browse all past trades with full details — buy/sell price, quantity, P&L, and return %. Filter by stakeholder, stock, type, or date. Use the ✏️ Edit button to correct a trade or 🗑️ Delete to remove it.
⚙️
Manage
Add or remove stakeholders (with PAN numbers) and stocks. Also contains the Backup & Restore panel to export your data as a file or import a backup from another device.
🗄️ Where Your Data Lives

This app stores all data in your browser's localStorage — a small database built into every browser. It is saved on this device, in this browser only. No data is ever sent to the internet, GitHub, or any server.

This means:

ScenarioData safe?
Close the browser tab✅ Safe — data persists
Restart the browser✅ Safe — data persists
Restart the computer✅ Safe — data persists

Open in Incognito / Private mode❌ Empty — incognito has its own storage, lost on close
A different person opens the site URL✅ Safe — they see their own empty app, not your data
⚠️ When Data Can Be Lost

The following actions permanently delete all data from this app and cannot be undone:

HIGH RISK
Clearing browser data — In Chrome: Settings → Privacy → Clear browsing data → checking "Cookies and site data" or "Hosted app data" wipes localStorage completely.
HIGH RISK
Uninstalling the browser — Removing Chrome/Edge/Firefox deletes all stored data.
HIGH RISK
Windows reset or new machine — A factory reset or switching computers loses all data.
CAUTION
Using Incognito mode — Data entered in an Incognito window is wiped when the window closes. Always use a regular browser window.
CAUTION
Storage limit — Browsers allow up to ~5 MB of localStorage. This is enough for several thousand trades. If the limit is hit, new data may not save.
💾 How to Back Up & Share Data

Use the Backup & Restore feature (in Manage) regularly to protect your data and share it between users.

1
Export (User A) — Go to Manage → Backup & Restore → click ⬇ Export Data. A file named portfolio-backup-YYYY-MM-DD.json downloads to your device.
2
Share the file — Send the file via WhatsApp, email, or Teams to the other user.
3
Import (User B) — Go to Manage → Backup & Restore → click ⬆ Import Data. Select the received file. A confirmation prompt will show what's in the file before anything is changed.
4
Confirm — Click OK. The import replaces all current data on this device with the backup. This cannot be undone — export your own data first if needed.
💡 Best practice: Export a backup after every significant session and store the file in a shared folder (Google Drive, OneDrive) as an additional safety net.
🔐 Login & Access

The app uses a single shared login. Credentials are fixed and cannot be changed from within the app. Contact the administrator if you need the username or password.

Your session stays active until you click ⏏ Logout or close the browser tab. Opening a new tab will require logging in again.
